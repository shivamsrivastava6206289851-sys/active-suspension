# Active Suspension System

## Overview
Developed and simulated an active suspension system for a quarter-car model using a Fuzzy-PID controller to improve ride comfort and suspension performance under varying road disturbances.

## Objectives
- Develop a quarter-car suspension model.
- Design a Fuzzy-PID controller.
- Simulate system dynamics in MATLAB/Simulink.
- Evaluate suspension performance under different road inputs.

## Tools Used
- MATLAB
- Simulink
- SolidWorks
- Fuzzy Logic Control

## Repository Contents
- `active_suspension.zip` — Complete project files.
- `image.png` — Project image.
- `README.md` — Project documentation.

## How to Use
1. Download `active_suspension.zip`.
2. Extract the archive.
3. Open the MATLAB/Simulink files in MATLAB.
4. Run the simulation and review the results.
